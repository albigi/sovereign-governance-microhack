# Finish

> **Status (23 Nov 2026): challenges 1 to 4 validated live; the lab teardown is not yet validated.** See [Setup](../Readme.md#setup).

**Learning objective:** take one application from a sovereign requirement set to enforced controls, a reviewed exception and a reproducible evidence pack, and explain each step to an auditor.

**Prerequisites:** challenges [1](challenge-01.md), [2](challenge-02.md), [3](challenge-03.md) and [4](challenge-04.md) completed.

**Value readout:** saves the end-to-end manual effort from requirement set to evidence for one application; measured as the sum of the four challenge measurements ([results](../Readme.md#value-readout)).

Congratulations: you can now answer the three questions this MicroHack set out with.

| Question | Where you answered it |
|---|---|
| Which sovereign requirements apply to this application? | [Challenge 1](challenge-01.md) |
| What happens with a justified exception? | [Challenges 2](challenge-02.md) and [3](challenge-03.md) |
| How do I prove compliance to an auditor? | [Challenge 4](challenge-04.md) |

## Clean up

After an Azure run, remove the lab resources with [Finish, including after a failure](../labautomation/README.md#finish-including-after-a-failure). After either route, delete the local catalogue extract and generated files in `tools/gspp/out/` and `tools/exemptions/out/`.
